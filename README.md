# Eco Data SP 🌱📊

**Eco Data SP** is a sustainability data platform designed to transform scattered environmental and consumption records into actionable insights.

## Project goal
Many small organizations manage water, energy, cost and sustainability data across bills, spreadsheets and PDFs. Eco Data SP aims to centralize these records, validate them, calculate indicators and present clear information for decision-making.

## MVP scope
**Manual/CSV Data → Validation → SQLite Storage → Analytics → Dashboard → Alerts & Reports**

The MVP will cover organization/unit registration, water and energy monitoring, cost tracking, estimated environmental/CO₂e indicators, historical trends, simple variation alerts, sustainability goals, CSV import and reports.

> The first MVP does not require IoT devices or an LLM. The priority is validating the data workflow and usefulness of the indicators before adding more complex technology.

## Initial stack
Python · CustomTkinter · SQLite · Pandas · Matplotlib

## Roadmap
- **v1.0:** dashboard, water, energy, emissions, goals, alerts, history, CSV import and reports.
- **v1.5:** statistical analysis and anomaly detection.
- **v2.0:** web application.
- **v2.5:** APIs and multi-organization support.
- **v3.0:** AI-assisted analysis and recommendations where they provide measurable value.

## ESG perspective
Eco Data SP considers environmental visibility, accessible sustainability information, and economic efficiency. Estimated indicators will be clearly distinguished from measured consumption.
